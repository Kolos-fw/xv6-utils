# xv6-utils

Утилиты и системные вызовы для xv6 (RISC-V), написанные в рамках факультатива по операционным системам.

## Что внутри

### Пользовательские утилиты (`user/`)
- `sleep.c` — приостановка процесса на N тиков (системный вызов `pause`).
- `countdown.c` — обратный отсчёт с паузами.
- `head.c` — вывод первых N строк файла.
- `find.c` — поиск файла по имени (частичная реализация обхода директорий).
- `getppid.c` — вывод PID родительского процесса.
- `count_children.c` — вывод количества живых дочерних процессов.
- `childtest.c` — тестовая программа: создаёт 3 процесса через `fork()`, проверяет `getppid()`, `count_children()` и `wait()`.
- `vmprint.c` — вывод дерева страниц текущего процесса.
- `vmperms.c` — вывод прав доступа (rwxu) для каждой страницы процесса.
- `vmstat.c` — статистика по таблицам страниц (количество уровней, листьев, страниц с/без флагом `U`).

### Системные вызовы (`kernel/`)
- `sys_getppid()` — добавлен в `kernel/sysproc.c`. Возвращает PID родителя текущего процесса.
  - Использует `myproc()` для получения текущего процесса.
  - Защищён спинлоком `wait_lock`.
  - Для `init` возвращает -1.
- `count_children()` — добавлен в `kernel/sysproc.c`. Возвращает количество живых дочерних процессов у текущего процесса.
  - Использует `myproc()` для получения текущего процесса.
  - Защищён спинлоком `wait_lock`.
  - Проходит по всей таблице процессов (`proc[NPROC]`).
  - Считает процессы, у которых `p->parent == me`.
- `sys_vmprint()` — вызывает `vmprint(myproc()->pagetable)` для обхода дерева страниц и вывода в лог.
- `sys_vmperms()` — вызывает `vmperms(myproc()->pagetable)` для вывода прав доступа к страницам.
- `sys_vmstat()` — вызывает `vmstat(myproc()->pagetable)` для сбора статистики по таблицам страниц.

## Стек
C, xv6, RISC-V, системные вызовы, ядро ОС.

## Как собрать
Скопировать файлы в соответствующие директории исходников xv6-riscv и выполнить `make qemu`.
