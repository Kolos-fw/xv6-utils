# xv6-utils

Утилиты для xv6 (RISC-V), написанные в рамках факультатива по операционным системам.

## Что внутри
- `sleep.c` — приостановка процесса на N тиков (использует системный вызов `pause`).
- `countdown.c` — обратный отсчёт с паузами.
- `head.c` — вывод первых N строк файла.
- `find.c` — поиск файла по имени (частичная реализация обхода директорий).

## Стек
C, xv6, RISC-V, системные вызовы (`open`, `read`, `close`, `fstat`).

## Как собрать
Скопировать в директорию `user/` в исходниках xv6-riscv и выполнить `make qemu`.
