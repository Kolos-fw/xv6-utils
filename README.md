# xv6-utils

Утилиты и системные вызовы для xv6 (RISC-V), написанные в рамках факультатива по операционным системам.

## Что внутри

### Пользовательские утилиты (`user/`)
- `sleep.c` — приостановка процесса на N тиков (системный вызов `pause`).
- `countdown.c` — обратный отсчёт с паузами.
- `head.c` — вывод первых N строк файла.
- `find.c` — поиск файла по имени (частичная реализация обхода директорий).
- `getppid.c` — вывод PID родительского процесса.

### Системные вызовы (`kernel/`)
- `sys_getppid()` — добавлен в `kernel/sysproc.c`. Возвращает PID родителя текущего процесса.
  - Использует `myproc()` для получения текущего процесса.
  - Защищён спинлоком `wait_lock`.
  - Для `init` возвращает -1.

## Стек
C, xv6, RISC-V, системные вызовы, ядро ОС.

## Как собрать
Скопировать файлы в соответствующие директории исходников xv6-riscv и выполнить `make qemu`.
